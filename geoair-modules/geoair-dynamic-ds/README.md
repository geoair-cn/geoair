# GeoAir Dynamic DS 模块使用指南

## 模块介绍

GeoAir Dynamic DS 模块提供了动态数据源管理功能，支持运行时切换数据源，为多数据源应用提供了便捷的解决方案。

 
## 模块说明

geoair-dynamic-ds 模块提供了以下功能：

- 动态数据源管理
- 运行时切换数据源
- 支持 GeoTools DataStore 管理
- 支持简单数据源管理

 
 

## 功能特性

- 支持动态注册数据源
- 支持运行时切换数据源
- 支持 GeoTools DataStore 管理
- 支持简单数据源管理
- 提供数据源获取接口

## 依赖关系

- **geoair-dynamic-ds**：核心功能模块
