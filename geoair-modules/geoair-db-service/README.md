# GeoAir DB Service 模块使用指南

## 模块介绍

GeoAir DB Service 模块提供了数据库服务功能，包括数据源管理、表管理等，为数据库操作提供了便捷的接口。

## 目录结构

 

## 模块说明

### 1. geoair-db-service-core

数据库服务核心模块，提供了数据库服务的核心功能，包括数据源管理、表管理等。

## 快速开始

### 1. 引入依赖

在 Maven 项目中，添加以下依赖：

```xml
<dependency>
    <groupId>cn.geoair.devkit</groupId>
    <artifactId>geoair-db-service-core</artifactId>
    <version>J8.1.0-SNAPSHOT</version>
</dependency>
```
